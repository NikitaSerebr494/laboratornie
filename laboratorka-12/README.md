# Итоговый проект — учёт печатных заказов (вариант 10)

Автор: _укажите ФИО и группу_. Вариант 10. Python 3.13 (проверено на 3.13.14),
сторонних библиотек нет, интернет не нужен.

`amount` — количество страниц, `completed` — заказ напечатан.

## Состав

| Файл | Ответственность |
|---|---|
| `logic.py` | проверка записей, добавление, поиск, статус, удаление, статистика |
| `storage.py` | чтение и запись JSON без консольного ввода-вывода |
| `main.py` | меню, ввод, сообщения, вызовы функций |
| `data.json` | рабочий набор записей |
| `test_logic.py`, `test_storage.py` | автоматические проверки |
| `gui.py` | необязательный графический просмотр и поиск (tkinter) |

Запуск:

```
python main.py
python test_logic.py
python test_storage.py
python gui.py        # дополнительное задание, консольную версию не заменяет
```

Пути строятся от `Path(__file__).resolve().parent`, поэтому папку можно распаковать
куда угодно и запускать без абсолютных путей.

## Формат данных

`data.json` — список записей:

```json
[
  {"id": 1, "title": "Визитки для салона", "category": "визитки", "amount": 200, "completed": true},
  {"id": 2, "title": "Буклет выставки", "category": "буклеты", "amount": 24, "completed": false},
  {"id": 3, "title": "Листовки акции", "category": "листовки", "amount": 500, "completed": true},
  {"id": 4, "title": "Визитки курьера", "category": "визитки", "amount": 100, "completed": false}
]
```

Правила: `id` — положительное целое, уникальное; `title` и `category` — непустые строки;
`amount` — целое ≥ 0, `bool` вместо числа не принимается; `completed` — строго `bool`;
корень — список, запись — словарь, все пять ключей обязательны, лишние ключи сохраняются.
Новый ID — максимум существующих плюс 1, для пустого списка — 1; после удаления ID не
перенумеровываются.

Ожидаемая статистика для набора выше: всего 4, напечатано 2, не напечатано 2, сумма
страниц 824; по категориям: буклеты 24, визитки 300, листовки 500.

## Контракты функций

- `validate_records(records)` — только проверка, при нарушении `ValueError`;
- `add_record(records, title, category, amount)` — добавляет запись со статусом `False`,
  обрезает пробелы, возвращает новую запись;
- `find_records(records, query)` — список записей, исходные данные не меняет, пустой
  запрос — `ValueError`;
- `set_completed(records, record_id, completed)` — `True` при успехе, `False` если ID
  не найден;
- `delete_record(records, record_id)` — `True` при успехе, `False` если ID не найден;
- `statistics(records)` — словарь `total`, `completed`, `pending`, `amount`,
  `by_category` (категории сравниваются после `strip()`), исходные данные не меняет;
- `load_records(path)` / `save_records(path, records)` — только файлы; сохранение идёт
  через `data.json.tmp` и замену, поэтому при ошибке прежний файл остаётся целым.

Состояние живёт в списке, который создаётся при загрузке и передаётся аргументами;
изменяемых глобальных переменных нет.

## Сценарии приёмки — ручная проверка

Каждый сценарий прогнан во временной папке с копией модулей. Фактические результаты:

| Сценарий | Результат |
|---|---|
| `data.json` нет | «Файл data.json не найден, начинаем с пустого списка», меню доступно |
| В файле `[]` | «Загружено записей: 0», статистика `0/0/0/0` |
| Добавлены 4 и 2, вторая завершена | «Всего: 2, напечатано: 1, не напечатано: 1, сумма страниц: 6» |
| Название введено как `" Python "` | Сохранено `Python` |
| Поиск `PY` при названии `Python` | Запись найдена |
| Пустое название, `amount=-1`, `amount=abc` | Повторный ввод, лишняя запись не появилась |
| Изменение статуса неизвестного ID 999 | «Запись с ID 999 не найдена, данные не изменены» |
| Удаление отменено ответом «нет» | Запись сохранена |
| Удалена запись ID 1 из списка с ID 1 и 2 | Осталась запись ID 2, новая получила ID 3 |
| Сохранение и перезапуск | Поля и статусы восстановлены (2 записи, одна напечатана) |
| Повреждённый JSON | Запуск прерван, сообщение с позицией ошибки, файл не изменён (хэш совпал) |
| Повторяющийся ID в файле | «запись 2: повторяющийся id 1», файл не изменён |
| Ошибка сохранения (`data.json.tmp` занят) | «Не удалось сохранить данные», программа осталась в меню, `data.json` не изменён |

## Автоматические проверки

`test_logic.py` (14 проверок): пустой список, повторяющиеся названия, строгие типы полей
(`id=true`, `id=1.0`, `amount=true`, `completed="false"`), неизвестный ID для статуса и
удаления, поиск без учёта регистра, статистика по двум категориям, слияние категорий
с пробелами по краям, неизменность данных в поиске и статистике, новый ID после удаления.

`test_storage.py` (8 проверок): сохранение и повторное чтение, читаемая кириллица в UTF-8,
полная замена файла, отсутствие `.tmp`, отсутствующий файл, битый JSON, неверная
кодировка, сохранение старого файла при ошибке записи. Используется
`tempfile.TemporaryDirectory()`.

## Дополнительное задание

`gui.py` показывает записи в `Treeview`, ищет через `find_records` и печатает сводку из
`statistics`; пустой запрос и отсутствие совпадений выводятся в диалоге. Проверено
скрытым запуском окна: 2 строки в таблице, статус `Всего: 2, напечатано: 1, не напечатано:
1, сумма страниц: 224`, поиск «букл» оставляет одну строку.
